# Odin Project: Landing Page

A webpage built from scratch using HTML5 and CSS Flexbox as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

Live preview : https://herculesmar.github.io/odin-landing-page/

## 📌 Project Overview

The goal of this project was to take a raw design layout and convert it into a fully structured web page without relying on external frameworks. The entire page was created from scratch, focusing on layout positioning, alignment, and element styling.

---

## 🛠️ What I Used

- **HTML5:** Structuring page sections with containers (`<div>`), lists (`<ul>`, `<li>`), headings, and action elements (`<button>`).
- **CSS3:** Pure CSS for styling components, managing background colors, typography, borders, and rounded corners (`border-radius`).
- **CSS Flexbox:** Heavily utilized for full-page positioning, including:
  - `display: flex`
  - `flex-direction` (`row` and `column`)
  - `justify-content` and `align-items`
  - `flex-grow` and `flex-shrink`

---

## 🧠 What I Learned

Building this project helped reinforce fundamental web development concepts:

- **Flexbox Positioning:** Learned how to align header links, center hero elements, and build horizontal card groups using `justify-content` and `align-items`.
- **Space & Margins:** Understood how to distribute spacing across layout sections using padding, margins, and flex gaps.
- **Component Styling:** Practiced styling interactive elements like buttons using border resets, background colors, and custom sizing.
- **Git & GitHub Workflow:** Initialized a local repository, tracked changes through structured commits, and pushed the finished project to GitHub.
